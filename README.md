# 📚 Projeto ETEC – Atividade de PW2

## 📌 Sobre o Projeto  
Este projeto foi desenvolvido como parte da disciplina de **Programação Web II (PW2)** da ETEC.  
O objetivo é criar uma página web moderna e funcional, aplicando conceitos de desenvolvimento front-end, organização de layout e boas práticas de programação.

A proposta do site é apresentar informações institucionais da ETEC, incluindo cursos oferecidos, missão, visão e valores, com foco em uma experiência de usuário clara e atrativa.
